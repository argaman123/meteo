Lead corrections (2026-07-08, layer-bar step 2): the look checkbox rows I named איזותרמות/איזוטכות/חלקיקים were rejected — he wants the *kind* vocabulary, identical across layers: צבעים (colormap), קונטורים (contours), אנימציה (particles). Contour rows also show their identity color as a dot. And the look list must NOT auto-unfold when a layer activates — disclosure is a separate explicit chevron button the user controls.

**Why:** menu labels are UI controls, not meteorology lessons — the layer name already carries the domain meaning; the row says which *rendering* it toggles. Auto-unfolding makes the card jumpy and takes control from the user.

**How to apply:** new looks get a generic Hebrew kind-name reused everywhere ([[verb-noun-method-names]] — one concept, one name); any new collapsible UI defaults to explicit user-controlled disclosure, not state-driven auto-expansion.
