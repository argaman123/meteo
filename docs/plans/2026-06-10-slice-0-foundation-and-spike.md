# Slice 0 — Foundation & Engine Spike Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Also required:** consult the `angular-v22` skill (the lead's custom-built v22 accuracy layer —
> not official) **together with** the official `angular-developer` and `angular-new-app` skills before
> writing any Angular code, and CLAUDE.md (operating law) before everything. CLAUDE.md rules override
> habits: **no code comments**, signals + signal-stores, logical CSS properties only, engine libraries
> imported only in `src/app/map/engine/`.

**Goal:** Scaffolded Angular 22 app with self-hosted basemaps (dark/light/colorful) on a MapLibre globe behind an engine adapter, plus the go/no-go spike: a temperature colormap + animated wind particles from generated fixture grids, with perf HUD, quality knobs, and a Chrome-for-Testing 113 smoke test.

**Architecture:** App per CLAUDE.md §5 structure. The only module importing maplibre/deck.gl/weatherlayers is `src/app/map/engine/`. Layers are declarative definitions (v1) decoded by a pure `field-grid` module (verified with temporary tests — the operational-hazard logic). Fixtures are generated by a repo script in the lead-approved backend JSON shape; basemap binaries are prebuilt downloads (gitignored, fetched by script).

**Tech Stack:** Angular 22 (zoneless, signals, Vitest), Tailwind v4, Angular CDK (when needed), MapLibre GL JS ≥5, deck.gl 9.1 (`@deck.gl/core` + `@deck.gl/mapbox`), WeatherLayers GL (MPL-2.0), Protomaps PMTiles + `@protomaps/basemaps` styles, Heebo (variable, OFL), Node 26 / TS 6.

| Topic | Decision |
|---|---|
| UI font | **Heebo** (variable, self-hosted via `@fontsource-variable/heebo` files) |
| Default theme | **Dark**; all three basemap styles (dark / light / colorful-terrain) ship in Slice 0 |

| Wind format | Separate **speed + direction (meteorological degrees, "from")** grids — the backend computes them from u/v; client derives u/v back for the particle renderer |
| Units in fixtures | temperature °C; wind speed **knots** (per lead — units vary per grid); each grid JSON carries a `units` field (assumption — verify against the real backend); client converts kt→m/s for rendering |
| Unit tests | **None committed.** Temporary Vitest checks may be written to verify hazard logic during development, then deleted before commit (lead 2026-06-10; amends the earlier testing decision) |
| Routing | **Front page only** (`/map` + redirects). The old-app cutover route map is deferred until the lead supplies the page list (much later, per lead) |
| Document direction | `<html lang="he" dir="rtl">` default; all CSS logical → flipping is config, not rework |
| Basemap label language | `he` with local-name fallback (also serves as the Hebrew-glyph/RTL verification) |

- [ ] **Step 1: Write the doc**

1. **Why:** internal network has no registry; every dependency and asset is hand-carried.
2. **npm packages (outside → inside):** on the online machine `npm ci --cache .npm-cache` keeps a complete tarball cache; hand-carry the repo **including `.npm-cache` and `package-lock.json`**; inside run `npm ci --offline --cache .npm-cache`. 3. **Static assets:** table of everything self-hosted, where it came from, how to re-fetch — Heebo (`@fontsource-variable/heebo` → `public/fonts/heebo/`), basemap tiles + terrain raster (`tools/fetch-basemap.ps1`, prebuilt downloads), basemap styles (prebuilt JSON from maps.protomaps.com + the three self-hosting field patches), glyphs/sprites (protomaps/basemaps-assets), RTL plugin (npm → `public/basemaps/rtl/`), satellite fixture (NASA Worldview, public domain).
4. **Rules recap:** no CDN URLs anywhere in code or styles; new deps need sign-off (CLAUDE.md §7); licenses ship next to vendored files.
5. **Large binaries:** `*.pmtiles` are gitignored; they are **build artifacts** recreated by the scripts above and hand-carried alongside the repo when moving inside.

param([string]$BuildDate = (Get-Date -Format 'yyyyMMdd'), [int]$MaxZoom = 7)
$bin = "tools/bin/pmtiles.exe"

  Write-Host "Download go-pmtiles (Windows x86_64) from https://github.com/protomaps/go-pmtiles/releases and place it at $bin"

}

- [ ] **Step 2: The adapter — `src/app/map/engine/map-engine.ts`**

```ts
import { Service } from '@angular/core';
import maplibregl from 'maplibre-gl';
import { Protocol } from 'pmtiles';
import 'maplibre-gl/dist/maplibre-gl.css';

export type BasemapId = 'dark' | 'light' | 'colorful';
export type ViewMode = 'globe' | 'flat';

@Service()
export class MapEngine {
  private map: maplibregl.Map | null = null;
  private viewMode: ViewMode = 'globe';

  init(container: HTMLElement, basemap: BasemapId): void {
    const protocol = new Protocol();
    maplibregl.addProtocol('pmtiles', protocol.tile);
    maplibregl.setRTLTextPlugin('/basemaps/rtl/maplibre-gl-rtl-text.js', true);
    this.map = new maplibregl.Map({
      container,
      style: `/basemaps/styles/${basemap}.json`,
      center: [35, 31],
      zoom: 4,
    });
    this.map.on('style.load', () => this.applyProjection());
  }

  setBasemap(id: BasemapId): void {
    this.map?.setStyle(`/basemaps/styles/${id}.json`);
  }

  setViewMode(mode: ViewMode): void {
    this.viewMode = mode;
    this.applyProjection();
  }

  destroy(): void {
    this.map?.remove();
    this.map = null;
  }

  private applyProjection(): void {
    this.map?.setProjection({ type: this.viewMode === 'globe' ? 'globe' : 'mercator' });
  }
}
```

Verify against installed maplibre v5 types: `setProjection` signature, RTL plugin filename in the vendored package, CSS import path. Adjust to what the types say — then this file is the locked pattern.

```ts
export type FieldGridDocument = {
  parameter: string;
  level: string;
  units: string;
  runTime: string;
  forecastHours: number;
  startLat: number;
  startLon: number;
  deltaLat: number;
  deltaLon: number;
  rows: number;
  cols: number;
  values: number[][];
};

export type FieldGrid = {
  parameter: string;
  units: string;
  runTime: string;
  forecastHours: number;
  bounds: [number, number, number, number];
  width: number;
  height: number;
  data: Float32Array;
};

export type VectorField = {
  bounds: [number, number, number, number];
  width: number;
  height: number;
  data: Float32Array;
};

export function parseFieldGrid(doc: FieldGridDocument): FieldGrid {
  const data = new Float32Array(doc.rows * doc.cols);
  for (let r = 0; r < doc.rows; r++) {
    for (let c = 0; c < doc.cols; c++) data[r * doc.cols + c] = doc.values[r][c];
  }
  const north = doc.startLat;
  const south = doc.startLat + doc.deltaLat * (doc.rows - 1);
  const west = doc.startLon;
  const east = doc.startLon + doc.deltaLon * (doc.cols - 1);
  return {
    parameter: doc.parameter,
    units: doc.units,
    runTime: doc.runTime,
    forecastHours: doc.forecastHours,
    bounds: [west, south, east, north],
    width: doc.cols,
    height: doc.rows,
    data,
  };
}

const KNOTS_TO_METERS_PER_SECOND = 0.514444;

export function convertKnotsToMetersPerSecond(grid: FieldGrid): FieldGrid {
  const data = new Float32Array(grid.data.length);
  for (let i = 0; i < grid.data.length; i++) data[i] = grid.data[i] * KNOTS_TO_METERS_PER_SECOND;
  return { ...grid, units: 'm/s', data };
}

export function toVectorField(speed: FieldGrid, direction: FieldGrid): VectorField {
  const data = new Float32Array(speed.width * speed.height * 2);
  for (let i = 0; i < speed.data.length; i++) {
    const rad = (direction.data[i] * Math.PI) / 180;
    data[i * 2] = -speed.data[i] * Math.sin(rad);
    data[i * 2 + 1] = -speed.data[i] * Math.cos(rad);
  }
  return { bounds: speed.bounds, width: speed.width, height: speed.height, data };
}

export function downsampleGrid(grid: FieldGrid, maxDimension: number): FieldGrid {
  if (grid.width <= maxDimension && grid.height <= maxDimension) return grid;
  const step = Math.ceil(Math.max(grid.width, grid.height) / maxDimension);
  const width = Math.ceil(grid.width / step);
  const height = Math.ceil(grid.height / step);
  const data = new Float32Array(width * height);
  for (let r = 0; r < height; r++) {
    for (let c = 0; c < width; c++) data[r * width + c] = grid.data[r * step * grid.width + c * step];
  }
  return { ...grid, bounds: grid.bounds, width, height, data };
}
```
